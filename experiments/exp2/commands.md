# Exp2 Experiment Commands

This document contains all commands needed to run Exp2 experiments.

---

## Prerequisites

### 1. Generate Task Data (if not already done)

```bash
cd symphony-data-generator
conda activate symphony-data-gen  # or use your environment
python src/quick_start.py
```

This will generate `symphony-data-generator/data/exp2/task_pool.jsonl`

---

## 1. Simulation Experiments

### 1.1 Shock A (A_unavailable)

```bash
python3 experiments/exp2/sim/exp2_sim.py \
  --n 1500 \
  --shock A_unavailable \
  --shock-point 750 \
  --seed 42 \
  --outdir experiments/exp2/sim/results/sim_exp2_robustness
```

**Results location**: `experiments/exp2/sim/results/sim_exp2_robustness/ShockA/[timestamp]/`

### 1.2 Shock B (A_degraded)

```bash
python3 experiments/exp2/sim/exp2_sim.py \
  --n 1500 \
  --shock A_degraded \
  --shock-point 750 \
  --seed 42 \
  --outdir experiments/exp2/sim/results/sim_exp2_robustness
```

**Results location**: `experiments/exp2/sim/results/sim_exp2_robustness/ShockB/[timestamp]/`

---

## 2. Real Execution Experiments

### 2.1 Shock A (A_unavailable)

```bash
python3 experiments/exp2/real/exp2_real.py \
  --tasks symphony-data-generator/data/exp2/task_pool.jsonl \
  --benchmark gsm8k \
  --n 1500 \
  --sample-with-replacement \
  --shock A_unavailable \
  --shock-point 750 \
  --seed 42 \
  --outdir experiments/exp2/real/results/gsm8k_replacement
```

**Note**: `shock-point=750` is `n//2` (default), ensuring equal tasks before and after for comparison.

**Results location**: `experiments/exp2/real/results/real_exp2_robustness/ShockA/[timestamp]/`

### 2.2 Shock B (A_degraded)

```bash
python3 experiments/exp2/real/exp2_real.py \
  --tasks symphony-data-generator/data/exp2/task_pool.jsonl \
  --benchmark gsm8k \
  --n 1500 \
  --sample-with-replacement \
  --shock A_degraded \
  --shock-point 750 \
  --seed 42 \
  --outdir experiments/exp2/real/results/gsm8k_replacement
```

**Results location**: `experiments/exp2/real/results/real_exp2_robustness/ShockB/[timestamp]/`

## 3. Generate Comparison Plots (Sim vs Real)

### 3.1 Shock A Comparison Plot

First find the latest result directories, then run:

```bash
# Method 1: Use latest results (recommended)
SIM_SHOCKA=$(ls -td experiments/exp2/sim/results/sim_exp2_robustness/ShockA/*/ | head -1)
REAL_SHOCKA=$(ls -td experiments/exp2/real/results/gsm8k_replacement/ShockA/*/ | head -1)

python3 experiments/exp2/plot/plot_sim_vs_real.py \
  --sim "$SIM_SHOCKA/trajectory_linucb.csv" \
  --real "$REAL_SHOCKA/trajectory_real.json" \
  --shock-point-sim 750 \
  --shock-point-real 750 \
  --shock-type A_unavailable \
  --out experiments/exp2/plot/sim_vs_real_ShockA.png
```

## Parameter Reference

### Simulation Parameters
- `--n`: Number of tasks (default: 1000)
- `--shock`: Shock type, `A_unavailable` or `A_degraded`
- `--shock-point`: Shock occurrence position (default: n//2)
- `--seed`: Random seed (default: 42)
- `--outdir`: Output directory

### Real Execution Parameters
- `--tasks`: **Required** - Task file path (generated by symphony-data-generator)
- `--n`: Number of tasks (default: 200)
- `--shock`: Shock type, `A_unavailable` or `A_degraded`
- `--shock-point`: Shock occurrence position (default: n//2)
- `--seed`: Random seed (default: 42)
- `--outdir`: Output directory
- `--no-plots`: Don't generate plots (optional)
- `--no-excel`: Don't generate Excel files (optional)

### Comparison Plot Parameters
- `--sim`: Sim trajectory CSV file path
- `--real`: Real trajectory JSON file path
- `--shock-point`: Shock point (if sim and real are the same)
- `--shock-point-sim`: Sim shock point
- `--shock-point-real`: Real shock point
- `--shock-type`: Shock type (for plot title)
- `--out`: Output image path

## Notes

1. **Task File**: Real experiments require running `quick_start.py` first to generate task files
2. **Shock Point**: Real ShockB uses `shock-point=400` instead of 500 to ensure enough post-shock tasks
3. **Task Count**: Real experiments use fewer tasks (200-500), Sim uses 1000, to control API costs
4. **Result Directories**: Each run creates a new timestamped directory, use latest directory for comparison
